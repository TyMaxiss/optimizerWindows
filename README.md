# optimize-windows.bat

Один файл, который после переустановки Windows 11 делает то же, что вы обычно
включаете вручную в [Optimizer 16.7](https://github.com/hellzerg/optimizer),
и дополнительно:

- убирает погоду с панели задач;
- убирает окно UAC «Разрешить этому приложению вносить изменения?»;
- удаляет браузер Microsoft Edge и Bing.

## Как запустить

1. Скачайте `optimize-windows.bat`.
2. Если Edge — ваш единственный браузер, сначала поставьте другой (Chrome,
   Firefox и т.д.). Это можно сделать и потом, без браузера:
   `winget install Google.Chrome` или `winget install Mozilla.Firefox`.
3. Запустите файл двойным кликом. Права администратора он запросит сам: окно UAC
   появится один раз, а дальше скрипт его отключает.
   Если Windows покажет «Система Windows защитила ваш компьютер», нажмите
   «Подробнее» → «Выполнить в любом случае».
4. В конце скрипт предложит перезагрузить компьютер. Часть настроек
   начинает работать только после перезагрузки.

Рядом со скриптом появится журнал `optimize-windows.log`. В конце скрипт
перечисляет то, что применить не удалось; обычно это значения, которые
Windows не даёт менять.

## Что делает

Пункты Optimizer, включённые на ваших скриншотах. Каждый повторяет код
соответствующей функции из исходников Optimizer 16.7: те же ключи реестра,
службы и задачи планировщика.

**Универсальное:** оптимизация производительности; убрать задержку меню;
оптимизация сети и троттлинга; отключить отчёты об ошибках, службу факса,
залипание клавиш, SmartScreen; отключить телеметрию Office, Firefox, Chrome,
NVIDIA, Visual Studio; отключить телеметрию (задачи планировщика), общий доступ
к медиаплееру, домашнюю группу, SMBv1, SMBv2.

**Windows 11:** классический проводник; без контактов в Проводнике; без
ограничения в 260 символов в пути; без Miracast («Передать на устройство»);
классический просмотрщик фото; выключить Insider Service; панель задач по
левому краю; выключить телеметрию, Cortana; улучшение конфиденциальности;
без рекламы; отключить телеметрию Edge и «Обнаружение» в Edge; игровой режим;
выключить Xbox Live, Game Bar, Windows Ink, проверку правописания, облачный
буфер обмена, Snap Assist; классическое контекстное меню; компактный режим
Проводника; отключить Copilot.

**Дополнительно:**

| Пункт | Как сделано |
|---|---|
| Погода на панели задач | В Windows 11 погоду показывает кнопка «Виджеты», поэтому виджеты отключаются политикой. Win+W тоже перестаёт работать. |
| Окно UAC | Администратор получает права без вопроса (`ConsentPromptBehaviorAdmin = 0`). Сам UAC не выключается, поэтому приложения из Microsoft Store работают как обычно. |
| Edge | Удаляется установщиком Edge; блокировку удаления вне ЕС скрипт снимает на время удаления. Затем убираются ярлыки, а Edge Update получает запрет ставить Edge заново. **WebView2 не трогается**: без него ломаются многие программы. |
| Bing | Удаляются приложения Bing (Bing Search, News, Weather и др.) и отключаются веб-поиск Bing и «Главное в поиске» в меню «Пуск». |

## Как пропустить пункт

Откройте файл в Блокноте. В конце, в разделе `ЧТО ВЫПОЛНЯТЬ`, поставьте `#` в
начале строки нужного пункта, например:

```powershell
# Step 'Удалить Microsoft Edge'                            RemoveEdge
```

Сохраняйте в кодировке UTF-8.

## Что стоит знать

Эти побочные эффекты есть и в самом Optimizer, скрипт их просто повторяет:

- **«Улучшение конфиденциальности»** отключает Windows Hello (вход по
  отпечатку пальца или лицу) и определение местоположения.
- **«Отключить телеметрию»** заодно отключает задачи синхронизации времени.
  Если часы начнут отставать, удалите в функции `DisableTelemetryTasks` две
  строки с `Time Synchronization`.
- **«Отключить облачный буфер обмена»** отключает и журнал буфера обмена (Win+V).
- **SMBv2 выключен**: этот компьютер больше не сможет раздавать папки по сети.
  Открывать папки на других компьютерах при этом можно.

Кроме того:

- Настройки пользователя применяются к той учётной записи, под которой
  скрипт получил права администратора.
- Если Edge не удалился, значит, Microsoft снова изменила защиту в своём
  установщике. Остальные настройки при этом всё равно применяются.
- Как вернуть Edge: удалите значение `Install{56EB18F8-B008-4CBD-B6D2-8C97FE7E9062}`
  в `HKLM\SOFTWARE\Policies\Microsoft\EdgeUpdate` и установите Edge с
  microsoft.com/edge.
